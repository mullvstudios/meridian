Meridian is a Create-focused survival modpack for Minecraft 1.21.1 on NeoForge, built for long-running worlds on the mullv.studio network and equally at home in singleplayer or on your own server.

You start with a pickaxe and end up running railways, flying aircraft and building submarines. Create and a large set of addons give you trains, planes, ships, cannons, radar and physics-driven contraptions. Around that sits a mostly-vanilla survival layer: food and farming mods, new structures to find, and tools to navigate and document the world.

## What you get

- **Engineering.** Create with Steam 'n' Rails, Create Aeronautics, Sable physics, Create Big Cannons, Create Radar, Create Submarine, Create: Enchantment Industry, Create Numismatics, Copycats+, Bits 'n' Bobs, Train Perspective, Threaded Trains, Simulated Coasters and more. CC: Tweaked is included for programmable machines.
- **Food, farming and building.** Farmer's Delight with its addons, the Let's Do series (Bakery, Brewery, Vinery, Candlelight, Meadow and others), Handcrafted, Another Furniture and Refurbished Furniture.
- **Exploration.** YUNG's Better structures, Dungeons and Taverns, Alex's Caves, Towns and Towers, Antique Atlas, Surveyor with Surveystones, and Waystones, so a long journey stays worth making.
- **Photography and music.** Exposure with its camera addons, Immersive Melodies and Pipe Organs.
- **Co-op survival.** Simple Voice Chat, Ping Wheel, Lootr, Better Combat, Take a Seat, and revive and corpse mechanics.
- **Quality of life.** EMI, Jade, AppleSkin, Controlify, Mod Menu, Searchables and Better Advancements.
- **Performance.** Sodium, Lithium, FerriteCore, ModernFix, ImmediatelyFast, Entity Culling, Distant Horizons and Iris for shaders.
- **Looks and sound.** A set of PBR and animation resource packs and several shader packs are bundled. Pick one under Options > Video Settings > Shader Packs.

The full, always-current mod list is on the Versions tab: open any version and look at the dependencies and files.

## Requirements

- Minecraft 1.21.1 and NeoForge 21.1.248 (the Modrinth App and most launchers set this up for you when you install the pack).
- 8 GB of RAM allocated is recommended, more for large bases and shaders. A modern GPU is recommended for shaders.
- A few Fabric-only mods run through Sinytra Connector. The first launch is slower while it prepares them.

## Installing and updating

Install from the Modrinth App, or download the .mrpack and import it into a launcher that supports Modrinth packs (Prism Launcher, ATLauncher and others).

Updates are published as new versions of this project, on a monthly schedule (versions look like 2026.10, with hotfixes as 2026.10.1). The Modrinth App shows an update button when a new version is out. Meridian also includes Modpack Update Checker, which shows the changelog in game and warns you before an update that needs a world backup. Always back up your world before updating.

## Servers

Meridian is the pack used on the official mullv.studio survival server. You can also host your own: use a server pack tool or install the NeoForge version above and the same mods. Mods marked client-only are not needed on the server.

## Network use

- Modpack Update Checker downloads a small version file from GitHub when the game starts, to see whether a newer version exists.
- The multiplayer server list comes with the mullv.studio server (play2.mullv.studio) pre-added. Nothing connects to it unless you join.
